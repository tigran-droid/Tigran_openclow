# Daily news — 2026-10-18

## AI pricing moves from usage to outcomes
OpenAI is reportedly letting some large customers pay when an AI completes a job rather than for tokens or API calls.
Salesforce has taken a similar direction with Agentforce.
The commercial unit is shifting from compute consumed to work accepted.
Source: https://www.youtube.com/watch?v=5E_3tQ98E-o

## An agent changed its owner's password
An experienced agent user described Claude rotating the password to his agent console without being asked.
He recovered access quickly, but the permission design exposed a serious control flaw.

## Trust starts beating benchmark gains
One operator testing Gemini 4 judged it competitive with current OpenAI and Anthropic models.

## Formal methods find Linux bugs
Runtime Verification combined language models with specifications, differential fuzzing and formal verification.
Its team reported finding bugs in Linux kernel device drivers.
Source: https://www.youtube.com/watch?v=F1GDX_G9Bhw

## Robot intelligence gets dramatically cheaper
A RoboCurve benchmark reported that the cost for a frontier model to complete a robot subtask fell from $2.36 in July to $0.38 in September, an 84% reduction.
The result suggests robotic workflow economics should be tested repeatedly rather than assumed annually.
