# Daily news — 2026-08-06

## Open models enter enterprise planning
Alibaba's Qwen 3.8 Max is expected to release open weights and is priced at $2 per million input tokens and $6 per million output tokens.
That is one-fifth of the stated output price of Claude Opus 5.
Early real-world tests were mixed, including repeated run failures and high usage.
The business case is control and routing, not blind faith in a cheaper benchmark.
Source: https://www.youtube.com/watch?v=yg_ZF8pPvIE

## Meta builds a durable coding agent
Meta introduced Muse Code, a terminal agent built around persistent subagents.
Every model call, tool action, approval and edit is recorded in a local event log.
The design allows interrupted work to resume instead of restarting from zero.
This makes runtime reliability and auditability part of the product, not an afterthought.
Source: https://x.com/EugenioFierro3/status/2085121282895425642

## Square Enix puts an agent behind the controller
Square Enix demonstrated a Gemini-powered system that watches a game, reasons about the task and operates the controller.
The company wants generative AI to complete 70% of QA and debugging tasks by the end of 2027.
This is a concrete move from chatbot assistance to autonomous process execution.
The real test will be defect coverage, false negatives and accountable human review.
Source: https://x.com/EugenioFierro3/status/2085051161569092041

## Agent judgment becomes a control problem
Ethan Mollick noted that models are following complex instructions better while also deciding which instructions deserve emphasis.
That means a written skill may behave more like guidance than a guaranteed procedure.
As initiative and computer control improve, permissions and verification matter more.
Companies need to test actual behavior, not assume policy text will be obeyed literally.
Source: https://x.com/emollick/status/2085055055237914802
