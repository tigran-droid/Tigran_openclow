# Daily news — 2026-08-22

## OpenAI pauses frontier reinforcement learning
OpenAI said it paused some reinforcement-learning work on planned frontier models.
The stated reason is cyber-critical capability and the need for more hardening and evaluation.
Release speed is no longer the only variable; access rules may change with model risk.
Source: https://www.youtube.com/watch?v=EfGF7QbJItA

## A strong local model gets smaller
Qwen3.8 27B was demonstrated running offline on high-end consumer hardware.
The reported practical requirement is roughly 24 to 32 GB of memory.
One agent test still ran for two hours and produced a broken game, showing the gap between benchmark strength and accepted work.
Source: https://www.youtube.com/watch?v=EfGF7QbJItA

## Cyber capability without raw-model access
Anthropic is reportedly putting Claude Mythos 5 behind defined security products rather than giving users unrestricted model access.
Outputs include vulnerability findings, severity and confidence ratings, and suggested fixes subject to human review.
Source: https://x.com/EugenioFierro3/status/2090944982509138227

## AI work gets a handover record
Shared threads in Codex and ChatGPT Work can create a fixed, read-only snapshot of an AI-assisted work session.
The feature is intended to preserve context behind pull requests, research and project handovers.
Source: https://x.com/EugenioFierro3/status/2090772975335157917
