# Daily news — 2026-08-13

## A playable 3D game in hours
One creator used Claude Opus 5 for the initial build and GPT-5.6 for refinement.
The first pass produced 10,400 lines of code across 33 modules with no asset files.
The model also tested the game and fixed several faults itself.
Yet balancing, progression, camera behaviour and basic enjoyment still required repeated human decisions.

## Too many skills can make an agent worse
A practical test removed a collection of Claude skills and reported better performance.
Every instruction competes for attention and can create conflicts.
Agent systems need pruning and evaluation, not endless accumulation.
Source: https://www.youtube.com/watch?v=XNQBCRcwXV4

## Easy agents meet the trust gap
Grok Bot was presented as a simpler route into AI agents while a separate analysis argued that AI optimism has a trust problem.
Lower setup friction expands access, but trust still depends on visible limits, review and recoverability.
Source: https://www.youtube.com/watch?v=kckD1hgkYvk

## AI may improve writing
One argument challenged the assumption that AI necessarily degrades writing.
Cheap drafting raises the value of editing, taste and clear thinking.
Businesses should measure useful communication rather than output volume.
