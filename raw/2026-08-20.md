It intercepts runtime calls to expose XR state and input control through the Model Context Protocol, and Meta says it only pulls screenshots when the agent asks, keeping frame rate untouched.

👁️ Any MCP-compatible agent, from Claude Code to Codex, gets vision, screenshots of exactly what you'd see in the headset, spatial awareness of walls and furniture, full controller input, head movement, Unity scene inspection, and menu navigation, without touching the app's code.

🧪 Meta describes three workflows: rapid iteration, where each feature is built and visually verified before moving on; streamlined debugging, where the agent reproduces a symptom, finds the root cause and proves the fix with a new screenshot; and natural-language test automation, where a plain English scenario gets reported pass or fail with visual proof. In early tests with Beat Games and other studios, agents reportedly ran full build-test-verify cycles unattended, though Meta notes these are pre-release examples.
