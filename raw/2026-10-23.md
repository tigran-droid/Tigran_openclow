## Build more responsive apps with the Decisions API
Source: https://openai.com/index/decisions-api/
Published: 2026-10-22T19:00:00+00:00

OpenAI made the Decisions API generally available. Built with GPT-6 Luna, it returns bounded answers from text, images and structured inputs as a probability, a choice from supplied values, or a score against ordered levels. OpenAI says it can make these decisions up to ten times faster than GPT-6 Luna through the Responses API. The release adds native GPT-Live integration, prompt caching, JSON input, images in question instructions, US and EU inference residency, and up to 400 questions in one request.

OpenAI reports several early customer results. Box said route selection across 30 certificate-of-insurance cases was about five times faster with the same accuracy as the Responses API. Datadog said risk scoring for agent-generated shell commands achieved 40 times faster p95 latency with comparable accuracy to available frontier models. Ramp reported four times faster decisions and 30 percent lower cost for AI cost attribution without sacrificing accuracy. Sierra reported under 280 milliseconds p95, about three times faster and 90 percent lower cost per call than its previous approach, with no drop in customer outcomes. Speak reported reducing time to next action in a live language-learning experience from 1.4 seconds to 0.13 seconds.

The API costs $0.10 per million uncached input tokens and $0.01 per million cached input tokens, with no output-token charges. OpenAI advises teams to define the possible answers and the context needed to distinguish them, then test on representative examples and set thresholds according to the costs of false positives and false negatives.
