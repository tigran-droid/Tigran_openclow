## Making An Actually Fun 3D Game with AI
Source: https://www.youtube.com/watch?v=qK4nV_LnXxQ
Published: 2026-08-13T01:53:16+00:00
Type: YouTube transcript

The creator rebuilt an earlier simple library game as a 3D roguelite. Claude Opus 5 produced the initial version in about 90 minutes: 10,400 lines of code across 33 modules, with textures, materials, characters, sound effects and music generated in code rather than supplied as asset files. The model opened the game in a browser, tested it, fixed bugs and attempted some balancing. It identified problems including an unreachable book state, children that never stopped disrupting the library and pressure from bosses overwhelming the chaos system.

Human testing immediately exposed more work. Controls were reversed, navigation and camera behaviour needed correction, a staff-development screen lacked a return path and a generated character did not match its reference well. The creator used a detailed design Markdown file to transfer context from Claude to GPT-5.6. GPT suggested fixing procedural reachability and progression stacking before judging difficulty, and adding a short interactive tutorial.

Further play revealed that a bully character was too fast, natural disasters were poorly balanced, levels looked too similar and the system needed substantial refinement to become genuinely replayable. The creator concluded that game developers were not displaced: code generation was fast, but the many creative decisions, trade-offs, balancing choices and judgments that make a game enjoyable remained.
